# Sistema de Pedidos

Sistema simples de gerenciamento de pedidos desenvolvido em C# com .NET 6.

## Funcionalidades

- Cadastro de clientes
- Cadastro de produtos
- Criação de pedidos
- Listagem de pedidos
- Listagem de pedidos por status
- Pagamento de pedido
- Cancelamento de pedido, desde que ainda não esteja pago
- Exibição do valor total do pedido
- Histórico básico de alterações do pedido

## Tecnologias utilizadas

- C#
- .NET 6
- ASP.NET Core Web API
- Swagger/OpenAPI
- LINQ
- Injeção de dependência
- xUnit

## Como executar

Abra o projeto no Visual Studio.

Execute o projeto `SistemaPedidos.Api`.

O Swagger será aberto automaticamente.

Caso não abra, acesse:
